## 7. 미뤄 둔 사소한 지적

태스크별 검토에서 나와 고치지 않고 적어 둔 것이다. 최종 검토가 모두 "나중에 해도 됨"으로 분류했다.

- `tools/port-app-src.mjs`: `--check`가 목록에 없는 남은 생성물을 잡지 못한다. 테스트의 외부 import를 지우는 규칙이 `node:` 내장 import도 지운다(지금 원본에는 해당 없음). 생성된 테스트에 빈 줄이 남는다.
- 저장: 깨진 JSON 파일이 알 수 없는 오류로 나온다(출력은 코드뿐이다). `calls`의 값이 객체가 아닌 틀린 설정이 말없이 무시된다. 임시 이름에 쓰고 이름을 바꾸는 코드가 세 곳에 있고 실패하면 임시 파일이 남는다. 실패한 시작이 빈 면접 폴더를 남긴다.
- 실행기: 종류 판별 표가 테스트 도구 두 파일에 있다. 흘림 검사가 실패했을 때 함께 돈 전제 검사를 죽이지 않는다.
- 테스트: 임시 폴더를 지우지 않는다. 일부 규칙(면접 목록의 순서, 설정의 일부 검사)에 직접 테스트가 없다. 추이 테스트 하나가 실제 시계를 쓴다. README 테스트가 낱말의 존재만 본다.
- 기억 옮기는 도구: Docker가 실패하면 스택이 그대로 나온다. 옵션을 잘못 주면 말없이 기본값을 쓴다. 본체의 갈래에 테스트가 없다.
- 문서: README의 권한 규칙 예시가 드라이브 문자 `c`로 적혀 있다(바꾸는 법은 적혀 있다).
